# 🌦️ WeatherWise – ML-Based Weather Prediction

WeatherWise is a Machine Learning-based weather prediction project that uses historical weather data to predict weather conditions. The project implements multiple Machine Learning classification algorithms and uses **Random Forest** as the final prediction model.

## 📌 Project Overview

WeatherWise aims to explore how Machine Learning can be used to analyze weather data and predict weather conditions based on different environmental parameters.

The project includes data preprocessing, exploratory data analysis, model training, evaluation, and a Streamlit-based user interface.

## ✨ Features

- Weather dataset analysis and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization using graphs and charts
- Correlation heatmap
- Multiple Machine Learning algorithms
- Model performance evaluation
- Weather prediction using Random Forest
- Interactive Streamlit user interface

## 🧠 Machine Learning Algorithms

The following classification algorithms were implemented and evaluated:

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

**Final Model:** Random Forest Classifier

## 📊 Model Evaluation

The models are evaluated using the following performance metrics:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

These metrics help evaluate how accurately the model predicts weather conditions.

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/Anjalipatil2407/WeatherWise.git
```

**Step 2: Navigate to the project folder**

```bash
cd WeatherWise
```

**Step 3: Install the required libraries**

```bash
pip install -r requirements.txt
```

**Step 4: Run the Streamlit application**

```bash
streamlit run app.py
```

The application will open in your browser.

## 📈 Project Workflow

1. Collect weather dataset.
2. Perform data cleaning and preprocessing.
3. Explore the dataset using visualizations.
4. Analyze relationships between weather features.
5. Train Logistic Regression, Decision Tree and Random Forest models.
6. Evaluate model performance using classification metrics.
7. Use the Random Forest model for weather prediction.
8. Integrate the model with the Streamlit interface.

## 🎯 Project Objective

The main objective of WeatherWise is to understand and implement Machine Learning techniques for weather prediction while gaining practical experience in data preprocessing, model development, evaluation, and application integration.
